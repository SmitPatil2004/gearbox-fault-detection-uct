# Gearbox Fault Detection — UCT ML Internship

Binary classification of gearbox condition (Healthy vs Broken Tooth) from
vibration data recorded on a SpectraQuest Gearbox Fault Diagnostics Simulator.
Four vibration sensors, load varied 0–90%.

**Data:** 20 tab-delimited files (10 healthy, 10 broken), 4 sensor channels,
~2.02M samples total  
**Approach:** folder-derived labels + Random Forest classification  
**Status:** Week 1 — data inspection and file catalogue complete

## Structure
- `notebooks/` — Jupyter notebooks
- `results/` — plots and metrics
- `worklog.md` — daily progress notes
